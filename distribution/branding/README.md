# ScreenStride Gesture Helper artwork

The approved icon is `screenstride-amber-refined-v1.png`: an amber screen,
ivory pointer and two motion trails on an opaque dark background. The master
is 1254 × 1254 RGB and was produced with built-in imagegen. The exact edit
prompt is in `screenstride-amber-refinement-prompt.txt`.

Run `swift tools/generate_icons.swift` at the repository root to regenerate
all opaque sRGB macOS icon sizes from this master.
